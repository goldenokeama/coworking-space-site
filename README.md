# Coworking Space 🧑‍💻☕

A clean, responsive landing page showcasing coworking spaces designed especially for _lazy developers_ who love comfort, coffee, and minimal effort.

This project demonstrates modern HTML structure and responsive CSS styling using Flexbox and positioning techniques.

---

## 🚀 Live Preview

[View the deployed site here](https://golden-coworking-space.netlify.app/)

---

## 🛠️ Built With

- **HTML5**
- **CSS3**
- **Google Fonts (Montserrat)**
- Flexbox layout
- CSS positioning (relative, absolute, sticky)

---

## ✨ Features

### 🔹 Responsive Layout

- Uses a centered container with `max-width`
- Flexible layout using `display: flex`
- Optimized for mobile and desktop viewing

### 🔹 Image Banner Overlay

- Positioned using `position: absolute`
- Demonstrates layering with relative parent containers

### 🔹 Sticky Chat Button

- Circular floating chat button
- Uses `position: sticky`
- Includes subtle box shadow for depth

### 🔹 Clean UI Design

- Modern typography with Montserrat
- Consistent spacing and padding
- Simple color palette for visual clarity

---

## 🎨 Design Highlights

- Dark header for contrast
- Warm accent color (`#cd6858`) for buttons and banners
- Sticky chat feature for improved UX
- Minimal and clean layout focused on readability
